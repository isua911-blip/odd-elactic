# Configurational fracture of a non-potential odd-elastic lattice — revision package

Self-contained reproduction package for the revised manuscript. It merges the
archived package (25 drivers, 26 modules under `src/`) with the ten new analysis
modules and five new figures written to address the referee report.

---

## ⚠️ Two things are not in this bundle

**Eight archived figures.** The copies available during the revision were
corrupted in transfer, so they must be supplied from the archived package before
LaTeX will build:

```
fig01_model_cycle              fig05_refinement_scaling
fig02_configurational_balance  fig06_propagation_and_branching
fig03_configurational_work_bridge  fig07_directional_driving
fig04_protocol_family          figA1_localization_ambiguity
```

Place them in `figures/`. The five `figNEW_*.pdf` files are complete.

**`data/`.** By design — the archived README specifies it is regenerated by the
rebuild, not shipped. Until it exists, `verify_results.py` and
`generate_figures.py` will fail on missing input; that is expected.

## Running it

```
bash rebuild_from_scratch.sh     # regenerates data/, hours
python verify_results.py         # checks numerical claims against data/
python generate_figures.py       # archived figures
python fig_bloch.py              # new figures; each reads figure_data/
pdflatex manuscript && bibtex manuscript && pdflatex && pdflatex
```

The new figure scripts cache their inputs in `figure_data/`, so restyling never
re-runs a lattice solve. Delete a cache file to force recomputation.

Verified in this environment: all 36 modules import; the new figures regenerate
from cache and reproduce their published values; the manuscript compiles to 46
pages with no undefined references and no overfull boxes above 20 pt. The full
`rebuild_from_scratch.sh` path was **not** executed here — it needs the complete
21-stage recomputation.

## Regenerating every figure

The thirteen figures come from three different paths. Run them in this order.

### 0. Environment

```
conda env create -f environment.yml     # or: pip install -r requirements.txt
```

### 1. Regenerate `data/`  (hours)

`data/` is not shipped. Everything in step 2 and step 3 reads it.

```
bash rebuild_from_scratch.sh            # runs recompute_all_data.py, 21 stages
python verify_results.py                # must pass before trusting any figure
```

`verify_results.py` aborts on a package-revision mismatch, so do not mix files
from different revisions.

### 2. Archived figures 1–7 and A1

```
python generate_figures.py
```

`generate_figures.py` **ships already patched**: `fig02` is a two-panel figure
and `fig05` a three-panel one, matching the captions in `manuscript.tex`. The
patch is recorded in `patch_generate_figures.py`, which refuses to re-run, and
the unpatched original is kept as `generate_figures.py.orig`. Do not restore the
original unless you also revert the two captions.

### 3. The five new figures

Each script caches its inputs in `figure_data/`. As shipped they replot from
cache in seconds. **To recompute from the lattice instead, delete the cache
first:**

```
rm figure_data/figNEW_*.json            # optional: forces full recomputation
python fig_closure.py                   # ~10 min   (domain scans at N_x=160)
python fig_bridge.py                    # ~15 min   (fits over five sizes)
python fig_criterion.py                 # ~10 min
python fig_plane.py                     # ~5 min    (31x31 modulus grid)
python fig_bloch.py                     # ~3 min    (no cache; always computes)
```

Times are single-core estimates. `fig_bloch.py` has no cache because the
Brillouin-zone sweep is cheap.

### 4. Compile and re-manifest

```
pdflatex manuscript && bibtex manuscript && pdflatex manuscript && pdflatex manuscript
python - <<'EOF'
import hashlib
from pathlib import Path
rows=[(hashlib.sha256(f.read_bytes()).hexdigest(), str(f.relative_to(Path('.'))))
      for f in sorted(Path('.').rglob('*')) if f.is_file() and f.name!='MANIFEST.sha256']
Path('MANIFEST.sha256').write_text('\n'.join(f'{h}  {p}' for h,p in rows)+'\n')
EOF
```

### Legibility

Figures are included at `\textwidth` = 6.50 in, and the generators use a 10.5 pt
base font, so the on-page font size is `10.5 x 6.50 / figure_width_in_inches`.
Keep the total width near 11 in for a multi-panel figure; that lands at about
6.3 pt, which is the working minimum here. `fig01` (14.1 in, 4.9 pt) and `figA1`
(12.7 in, 5.4 pt) are inherited from the archived package and sit below it.

### Checking the build

```
bash check_manuscript.sh
```

Compiles in a temporary directory and reports LaTeX errors, undefined
references, missing figures, overfull boxes, page count and any figure whose
on-page font falls below 5.6 pt. **`pdflatex -interaction=nonstopmode` exits 0
and still writes a PDF after a hard error**, so a build that looks successful can
hide a broken table; this script greps for `^!` explicitly.

### What to check afterwards

- `fig02` has two panels and `fig05` has three; if either still shows the old
  panel count, `generate_figures.py` was reverted.
- The new figures reproduce their published values. Two are self-reporting:
  `fig_plane.py` prints `max |G12/G11| on the A_o=0 axis`, which must be
  ~1e-16, and `fig_bloch.py` prints `c_crit/k_o`, which must approach 2.1213.
- The compile reports no undefined references and 46 pages.

Thirteen figures are referenced. Three of the five new ones are new content;
**two supersede panels of archived figures**, which must therefore be
regenerated before submission. Both are marked `% REGENERATE` in

| Archived figure | Action | Superseded by |

| `fig02_configurational_balance` | drop panel (c), regenerate as **two** panels | `figNEW_source_closure` |
| `fig05_refinement_scaling` | drop panel (b), regenerate as **three** panels, relabel | `figNEW_bridge` |

`fig02` panel (c) plotted the source-closure ratio approaching unity under
geometric refinement; that is the claim the revision retracts. `fig05` panel (b)
measured stress-fit residuals with the reconstruction radius scaled as
`max(2, 0.05*nx)`, the setting now shown never to refine the reconstruction.

Leaving either panel in place puts the figures in direct contradiction with the
text. The captions as shipped describe the regenerated layouts, so the figures
must be regenerated for caption and artwork to agree.

The other three new figures (`figNEW_modulus_plane`, `figNEW_criterion`,
`figNEW_bloch_flutter`) have no archived counterpart. `fig01`, `fig03`, `fig04`,
`fig06`, `fig07` and `figA1` are unaffected.

At thirteen figures the paper is at the upper end for the journal; folding the
two surviving panels of `fig02` into `figNEW_source_closure` would bring it to
twelve, but that is an editorial choice and was not made here.

## What changed

| Referee point | Outcome |
|---|---|
| M1 discrete source closure | attribution to reconstruction bias **disproved**; protocol rebuilt on two error gates |
| M2 amplitude calibration | $\alpha_J$ 1.269 → **1.008 ± 0.008**; root cause identified |
| M2 cross mode | unresolved → **−0.0130 ± 0.0004**, >20× its systematic floor |
| M3 actuator closure | $R_{\rm torque} = 1.0019$, exactly unity for any uniform gradient |
| M4 separating $A_o$ from $K_o$ | independent solver, verified **off** the lattice ray |
| M5 flutter | exact bulk law $c_{\rm crit} = (3/\sqrt2)\,k_o\sqrt{m/k}$ |
| M7 coarse-grained criterion | quantitative negative result |

Three archived claims were **retracted**:

1. *The 3 % reconstruction floor.* A synthetic smooth field through the identical
   pipeline gives 0.2–0.4 % — an order of magnitude too small to explain it. The
   archived closure was measured where the passive-drift gate is of order unity;
   there the same quantity varies over tens of percent with the annulus,
   reconstruction radius and quadrature step, so 1.154 → 1.032 was never a
   convergence sequence.
2. *"$J=G$ is recovered, not merely approached"* — softened to *consistent with*
   exact recovery, since it rests on a three-model extrapolation over five points.
3. *The representation numbers 6.81 / 9.35 / 5.08 %*, which used the superseded
   calibration. Recomputed they now **discriminate**: the microenergetic
   representation is favoured, the major-symmetric projection underpredicts by
   ≈ 1.7× at every activity.

## Two settings that govern everything

**Lattice-scale parameters must not scale with the domain.** Scaling the moving
least-squares radius with $L$ keeps the stencil at a fixed fraction of the
specimen, so the reconstruction never refines and $\alpha_J$ freezes near 1.14.
Geometric parameters scale; lattice-scale parameters do not.

**Closure numbers are meaningless without their gates.** Passive elasticity is
path independent, so a nonzero passive flux is noise in the units of the signal.
The passive field carries no $k_o$, so the gate
$\gamma = |J^{\rm passive}|/|\Delta J_{\rm odd}|$ closes by raising activity, not
by refining the mesh. The second gate $\varrho = |Q_{\rm res}/Q_o|$ measures the
coarse-grained field's departure from *continuum* equilibrium; four lattice
spacings from the tip it exceeds unity.

Recommended protocol: $a = N_x/4$, absolute fit radius, $R_i \gtrsim 16\,a_{\rm lat}$,
fitting window of radial span $\geq 6$, Williams basis to $\lambda = 5/2$,
periodic-image neighbour search.
